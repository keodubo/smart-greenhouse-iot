# Invernadero · Raspberry 16

Un solo flow para HiveMQ, el Sense HAT de la Raspberry 16, el Arduino del grupo 99 y el SONOFF 9. El publicador Python envía la misma lectura a los topics habituales del grupo y a `IIoT/grupo99/pi16/temperatura` y `IIoT/grupo99/pi16/humedad`. El flow escucha estos últimos para los sensores del Sense HAT. Cualquier cliente del broker público puede publicar en ellos.

1. En la Raspberry entrá en `~/smart-greenhouse-iot` y ejecutá `git pull --ff-only`. Si es una instalación nueva, ejecutá `bash preparar-demo.sh 9` para instalar las dependencias Python.
2. En Node-RED, pulsá STOP / DISARM en el controlador anterior y comprobá que se apague la lámpara. Exportá una copia de los flows. Deshabilitá las pestañas anteriores del controlador, display y prueba manual, y pulsá Deploy. Detené el publicador anterior con Ctrl+C.
3. Abrí el menú Import → select a file y elegí **node-red/invernadero-pi16.json**. Pulsá Import y Deploy. Aparece una sola pestaña **Invernadero · Raspberry 16**. El controlador arranca desarmado. El nodo del display usa el repositorio en `$HOME/smart-greenhouse-iot` del usuario que ejecuta Node-RED. Si lo instalaste en otra ubicación, ajustá las rutas de ese nodo.
4. Desde la raíz del repositorio ejecutá `raspberry-pi/.venv/bin/python raspberry-pi/greenhouse.py --pi16`. Mantené abierta la terminal. En Debug, **Lectura directa Pi 16** muestra el topic y el JSON recibido. **Estado Pi 16** muestra los campos temperature y humidity. Esperá lecturas antes de armar.
5. Pulsá ARM y esperá la siguiente temperatura. Por debajo de 30 °C pide ON y desde 31 °C pide OFF al SONOFF 9. El joystick permite arriba ON, abajo OFF y pulsación central AUTO mientras haya una temperatura vigente. Los LEDs muestran temperatura y humedad cada diez segundos. El Arduino sigue publicando nivel en `IIoT/grupo99/nivel`. El controlador publica estado en `IIoT/grupo99/estado`.
6. Para observar únicamente las lecturas destinadas al nuevo flow desde otra terminal, ejecutá `mosquitto_sub -h broker.hivemq.com -p 1883 -v -t 'IIoT/grupo99/pi16/+'`. Si no aparecen, verificá que el publicador se inició con `--pi16`. Cerrá la demo con STOP / DISARM y comprobá el apagado físico.
